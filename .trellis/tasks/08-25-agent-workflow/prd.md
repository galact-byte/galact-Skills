# agent-workflow Skill

## 目标
新增跨 Agent 运行时可复用的工作流 Skill，减少低风险任务的无效确认，同时保留破坏性操作、真实数据、生产环境、外部副作用、安全边界和重大架构选择的明确批准要求。

## 范围
- 新增 `skills/agent-workflow/SKILL.md`。
- 不修改现有渗透 Skill。
- 不引入第三方依赖。
- 不提交或推送 Git。

## 验收标准
- SKILL.md 包含合法 frontmatter，`name` 为 `agent-workflow`，description 以 `Use when...` 开头且只描述触发条件。
- 明确区分可自主执行、需澄清、需批准三类场景。
- 明确已批准范围内不重复确认，以及超出范围/风险等级变化时需重新批准。
- 明确按风险匹配验证强度和完成声明证据。
- 明确生产行为变更的 TDD 要求，以及非行为性修改的相称验证替代方案。
- 通过仓库现有静态校验。
