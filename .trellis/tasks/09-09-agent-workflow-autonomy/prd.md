# 扩充 agent-workflow 自治边界与验证原则

## 目标

扩充现有 `skills/agent-workflow/SKILL.md`，减少授权范围内的重复确认、过早停止和不完整交付，同时保留明确的批准要求。不得新建重复的工作流 Skill。

## 范围与约束

- 在现有结构中完善原则、决策顺序、批准边界、验证、TDD 和完成声明，补充正反例及离线检查。
- 只读参考全局 `AGENTS.md`、`CHANGES.md` 及相关 Skill，按实际文件提炼，不整份复制配置。
- 评估用户补充的七份自写材料：`creating-skills`、`distill-dataset-to-skills`、`change-log`、`code-audit-report`、`presentation`、`windows-python-launcher` 的 `SKILL.md`，以及 `frontend-design/taste.md`。仅吸收适用的通用原则，不导入这些 Skill，不修改全局安装文件。
- 不扩大既有授权；扩大边界的建议单独提出，不阻塞其他独立工作。
- 保留破坏性操作、外部副作用、生产访问、费用、数据安全、安装下载以及用户阶段检查点的明确批准要求。
- 遵守 Trellis：本次已获创建任务许可，实施仍须规划审阅后明确批准。
- 不批量导入第三方 Skill；不新增依赖；不修改无关文件和旧任务。初始阶段禁止提交、推送和发布；用户后续在验收后明确授权更新 `.gitignore`、README、`release_note.md` 并提交、推送、发布，按现有 v0.1.0 递增到 v0.1.1。
- README 必须保留既有内容与结构，只局部新增工作流说明和经官方文档核对的 npx 安装用法，不实际覆盖本机已安装 Skill。
- 用户后续明确要求：除非确有必要不使用子代理，推理强度按任务难度与风险选择；剩余复核由主会话完成，不再派遣检查或模型评估子代理。
- 用户后续单独授权的例外：完成本次 Skill 扩充后，检查 `C:/Users/g1582/.pi/agent/AGENTS.md`，若未明确表达上述两点则最小补充。仅此文件可改，其他全局配置与 Skill 仍只读。
- README 保持简洁，不加入私有数据管线、蒸馏来源和测试套件介绍；不改动 H1 数据产物的忽略规则。
