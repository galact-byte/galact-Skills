# Web 安全测试工具速查

本表供已明确授权的测试选择现场工具，不是自动扫描入口，也不是 Skill 的必装依赖。二进制、MCP 和代理均使用当前环境的真实配置；不要求私有路径文件，不预设代理端口。

## 使用前

1. 确认资产范围、账号、动作、请求数/速率/并发预算、回调与证据存放要求。
2. 通过当前工具清单或 `command -v <工具名>` 查找已安装能力，读取实际版本和 `--help`。工具不存在记 blocked 或转手工，不自动安装。
3. 按当前版本帮助设置显式预算、超时与输出位置。避免默认扫描范围、默认高并发和自动跟随范围外跳转。
4. 检查输出是否含 Cookie、令牌、个人数据；完整原件私有保存，报告脱敏。

## 侦察与模板扫描

| 能力 | 常用工具（可选） | 输入与边界 |
|---|---|---|
| 被动子域线索 | subfinder | 输入获准根域；发现的域名不是自动授权目标 |
| HTTP 存活与指纹 | ProjectDiscovery httpx | 只对范围内资产发请求；注意与同名 Python 包区分 |
| 定向路径检查 | ffuf | 少量有来源候选、明确速率和响应上限，不默认大字典 |
| 模板扫描 | nuclei | 先确认模板实际动作及版本；签名/模板名称不能代替权限审查 |
| SQL 注入补充 | sqlmap | 手工线索后按具体技术、预算与许可选择；不默认枚举库/表或导出 |

不同工具的纯 URL、JSON 和 JSONL 输出不能直接混用。给下一工具准备其当前文档支持的输入格式，并先用一个受控对象验证解析；不要把整份探测 JSON 当作 URL 列表。

扫描器告警是候选，需对应 Skill 的正常/变体对照与实际影响才能确认。无告警仅表示该轮覆盖未观察到，不能写资产安全。

## 请求复现与证据

- **Burp**：使用已配置代理历史及 Repeater，对一个明确端点做获准重放；主动扫描需另外确认动作与预算。
- **Playwright/浏览器工具**：从本会话真实工具清单选导航、交互、网络与截图能力，不猜 MCP 工具名。页面截图支持可见现象，但通常不包含完整 HTTP Header/响应体，需另保存网络证据。
- **DevTools**：用于 DOM sink、CSP、请求时序和脚本调用链；前端行为与服务器状态分别核对。

每条证据保存 UTC 时间、工具版本、原始请求响应、对照、对象归属和最终状态。单张截图、状态码或扫描器标签不代替因果证据。

## 并发

小组并行验证按 [竞态 Skill](hunt-race-condition/SKILL.md) 及其参考执行。Burp Repeater 并行组、Turbo Intruder、线程并发和 HTTP/2 单包技术有不同限制；没有同步能力就明确说明，不默认提供未附带的执行脚本。

## 逆向与可选扫描器

现场已有 reverse-skill、IDA/Ghidra、ILSpy、移动端工具或其他逆向能力时，读取真实入口与版本后使用；本仓库不包含它们。APK/JS 提取出的端点需回到 [攻击面总线](recognize-attack-surface/SKILL.md) 核对范围。发现凭据不等于获准登录其他系统。

如现场已有 AutoRedTeam-Orchestrator 或其他 detector：先检查实际暴露的 MCP/CLI 工具、认证、输入格式、请求副作用、预算和停止方式，不假定存在 `redteam detect` 等通用命令。它们可用于获准的基线或同类候选检查，不能代替手工确认，也不承诺固定时间完成。

## 停止条件

缺许可、范围外跳转、非测试对象、服务异常、意外秘密或不可控响应体出现时停止相关方向并保留最小证据。写入、支付、通知、脚本执行、数据读取与回调各需相应许可；“最小证明”、低金额或回滚均不能替代许可。
